Leyenda:

- R: Responsible
- A: Accountable
- C: Consulted
- I: Informed

## 2. Hoja de ruta sugerida

### Fase 0. Preparacion

- Validar alcance con direccion.
- Confirmar roles reales y nombres de cargos.
- Levantar inventario de documentos y registros actuales.
- Confirmar indicadores oficiales del periodo.

### Fase 1. Diseno funcional

- Aprobar backlog priorizado.
- Definir mockups de pantallas.
- Definir diccionario de datos.
- Validar reglas de negocio.

### Fase 2. Construccion MVP

- Modulo de planificacion.
- Modulo de objetivos e indicadores.
- Modulo de seguimiento.
- Modulo de revision por la direccion.
- Modulo de AC/AP.

### Fase 3. Cumplimiento y auditoria

- Modulo de reclamos y no conformidades.
- Modulo de control documental.
- Listas maestras.
- Reportes de auditoria.

### Fase 4. Madurez operativa

- Modulo financiero.
- Automatizaciones.
- Importaciones.
- Integraciones.

## 3. Entregables recomendados para solicitar a un proveedor

- analisis funcional detallado
- modelo de datos
- disenio de UX/UI
- plan de implementacion
- plan de migracion documental
- plan de capacitacion
- plan de pruebas
- manual de usuario y administrador
- matriz de trazabilidad requisitos versus funcionalidades

## 4. Preguntas de definicion pendientes

- El sistema sera solo interno o tambien tendra acceso para clientes o relatores.
- La captura de encuestas sera manual o digital en linea.
- Se requerira firma electronica para aprobaciones.
- Se mantendra repositorio documental dentro del sistema o conectado a otra plataforma.
- Habra integracion futura con SENCE o con el Libro de Clases Electronico.
